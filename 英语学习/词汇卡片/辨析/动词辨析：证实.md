
*选词口诀*

- 核对真假 → **verify**（通用）/ **authenticate**（辨伪专）
- 再确认 → **confirm**
- 盖章生效 → **validate**
- 撑起主张 → **substantiate**（首次）/ **corroborate**（旁证加固）
- 正式作证 → **attest**
- 证它合理 → **justify**（证“该不该”不证“是不是”）


*情景速记*

- 李博士发现了一种潜在的新抗生素。首先，他用质谱仪 **verify**​ 化合物的精确分子量。接着，他拿已知样本跑了一遍，**validate**​ 自己的测试方法是靠谱的。为了 **substantiate**​ "这化合物能杀超级细菌"的主张，他又补做了几十组实验。检索文献时发现前人也有类似结论，**corroborate**​ 了他的数据。写论文时，他得 **justify**​ 为什么这药要这么高剂量。后来独立实验室重复了实验，**confirm**​ 他的结果。为防止样品造假，法医化学家被请来 **authenticate**​ 原始样本的出处。最后投稿前，导师 **attest**​ 整件事的研究过程是诚实的。


*速查表*

| **<br><br>词<br><br>** | **<br><br>词源核心<br><br>** | **<br><br>证实角度<br><br>** | **<br><br>典型对象<br><br>** |
| --------------------- | ------------------------ | ------------------------ | ------------------------ |
| **verify**​           | 使为真                      | 核对事实对错                   | 数据、身份、声明                 |
| **validate**​         | 使有效                      | 盖章认可其成立                  | 票券、模型、方法                 |
| **substantiate**​     | 底下撑住                     | 用证据撑主张                   | 指控、说法（书面）                |
| **justify**​          | 使正当                      | 证合理（非证真）                 | 决策、行为、开销                 |
| **confirm**​          | 使之稳固                     | 再确认、打消疑                  | 预约、猜测、消息                 |
| **authenticate**​     | 证为真品                     | 辨伪（专）                    | 艺术品、签名、账号                |
| **corroborate**​      | 加力共证                     | 旁证加固                     | 证词、已有说法                  |
| **attest**​           | 去作证                      | 正式出面证明                   | 资质、文件、史实                 |
