
1.*情景速记*

- 小王奉命要把一份机密文件送到总部。刚出发，路上拥挤的人群 **hinder**​ 了他的步伐——只是拖慢，并不完全挡住。他拐进小巷，不料车轮卡进排水沟，深深 **impede**​ 了他前进，几乎拔不出来。好不容易挣脱，前方一辆翻倒的货车把整条路 **obstruct**​ 了——货物堆得严严实实，彻底堵死。他只好绕到后门，却发现一道铁栅栏 **block**​ 了入口，封得死死的。这时，沉重的背包带子断了，他只能抱着包裹跑，姿势别扭，严重 **hamper**​ 了他的动作。包里还装着备用的器材，额外重量 **encumber**​ 着他每一步。更麻烦的是，对方派来的眼线已经在附近设卡，**curb**​ 了他所有的可行路线，只留了一条陷阱路。那人得意洋洋，以为能就此 **thwart**​ 小王的计划。然而小王早有准备，他换上伪装，从下水道潜行而出，成功 **foil**​ 了对方的阴谋

- **hinder**：只是拖慢，不彻底阻挡         **impede**：卡住脚，难以挪动
- **obstruct**：堆东西堵住，正面堵塞      **block**：封死，一刀切
- **hamper**：束缚手脚，施展不开           **encumber**：负重拖累，背着包袱走
- **curb**：勒缰限制，不让选某些路         **thwart**：硬挡对抗，使计划落空
- **foil**：巧妙挫败，智取
    


2.*动词速查表*

| 单词            | 障碍程度 | 侧重      | 使用情形                |
| ------------- | ---- | ------- | ------------------- |
| **block**​    | 重    | 物理/抽象堵死 | 道路、提案、思路被一刀切封死，口语常用 |
| **curb**​     | 轻    | 限制、勒缰   | 控制通胀、热情、支出，强调“不让过头” |
| **encumber**​ | 中    | 负重拖累    | 被债务、责任、杂物拖累，书面语     |
| **foil**​     | 中重   | 巧妙挫败    | 阴谋、计划被智取破坏，文学/谍战味   |
| **hamper**​   | 中    | 束缚施展不开  | 天气、设备、条件限制导致效率低     |
| **hinder**​   | 轻    | 拖后腿、使慢  | 进度、发展被轻微阻碍，中性       |
| **impede**​   | 中    | 脚被卡住    | 交通、调查、进展受阻，正式书面     |
| **obstruct**​ | 中重   | 对面堆东西堵  | 视线、道路、司法被故意或无意堵塞    |
| **preclude**​ | —    | 逻辑排除    | 提前关闭可能性，使某事不可能发生    |
| **thwart**​   | 中重   | 横过来硬挡   | 计划、敌人被对抗性阻止，带敌意     |
